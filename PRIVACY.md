# Privacy policy — LangSwap

*English · [Français](#français) · [Español](#español)*

LangSwap (Android app `fr.langswap`) collects no personal data and shares none.

- **No account, no analytics, no advertising, no tracking.** The app contains no third-party SDK that sends data anywhere.
- **Everything stays on your device**: your search history and settings are stored locally, in the app's private storage. Uninstalling the app deletes them. They are not included in Android backups.
- **Network use is limited to downloading the language packs** you choose (Settings → Downloaded languages). By default they are served by GitHub (`raw.githubusercontent.com` and `github.com` release files, repository [gosanefr/langswap](https://github.com/gosanefr/langswap)); you can set another server in Settings → Advanced. Like any web server, the server receives your IP address and the files requested; see [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Searches are never sent over the network.
- **Links** in the About screen (Wiktionary, licences, source code) open in your browser.

Contact: [langswap@gosane.fr](mailto:langswap@gosane.fr) · Last updated: 2026-10-15.

## Français

LangSwap (appli Android `fr.langswap`) ne collecte ni ne partage aucune donnée personnelle.

- **Pas de compte, pas de statistiques, pas de publicité, pas de pistage.** L'appli ne contient aucun SDK tiers qui enverrait des données.
- **Tout reste sur votre appareil** : l'historique des recherches et les réglages sont enregistrés localement, dans le stockage privé de l'appli. Désinstaller l'appli les supprime. Ils ne sont pas inclus dans les sauvegardes Android.
- **Le réseau sert uniquement à télécharger les packs de langue** que vous choisissez (Config → Langues téléchargées). Par défaut, ils sont servis par GitHub (`raw.githubusercontent.com` et fichiers des releases de `github.com`, dépôt [gosanefr/langswap](https://github.com/gosanefr/langswap)) ; un autre serveur peut être réglé dans Config → Avancé. Comme tout serveur web, celui-ci reçoit votre adresse IP et les fichiers demandés ; voir la [déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Les recherches ne passent jamais par le réseau.
- **Les liens** de l'écran « À propos » (Wiktionnaire, licences, code source) s'ouvrent dans votre navigateur.

Contact : [langswap@gosane.fr](mailto:langswap@gosane.fr) · Mise à jour : 2026-10-15.

## Español

LangSwap (aplicación Android `fr.langswap`) no recopila ni comparte ningún dato personal.

- **Sin cuenta, sin estadísticas, sin publicidad, sin rastreo.** La aplicación no contiene ningún SDK de terceros que envíe datos.
- **Todo se queda en tu dispositivo**: el historial de búsquedas y los ajustes se guardan localmente, en el almacenamiento privado de la aplicación. Al desinstalarla se borran. No se incluyen en las copias de seguridad de Android.
- **La red solo se usa para descargar los paquetes de idioma** que eliges (Ajustes → Idiomas descargados). Por defecto los sirve GitHub (`raw.githubusercontent.com` y archivos de las releases de `github.com`, repositorio [gosanefr/langswap](https://github.com/gosanefr/langswap)); se puede configurar otro servidor en Ajustes → Avanzado. Como cualquier servidor web, recibe tu dirección IP y los archivos solicitados; consulta la [declaración de privacidad de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). Las búsquedas nunca pasan por la red.
- **Los enlaces** de la pantalla «Acerca de» (Wikcionario, licencias, código fuente) se abren en el navegador.

Contacto: [langswap@gosane.fr](mailto:langswap@gosane.fr) · Actualización: 2026-10-15.
